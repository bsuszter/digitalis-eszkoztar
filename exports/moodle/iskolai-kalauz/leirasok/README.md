# Az Iskolai kalauz Moodle-leírásai

A mappában minden Moodle-oldalhoz külön, közvetlenül bemásolható HTML-leírás található.

A kódot az adott Moodle-elem **Leírás** mezőjének HTML-nézetébe kell beilleszteni, majd be kell kapcsolni a **Leírás megjelenítése a kurzusoldalon** beállítást.

Az elemek címét nem ismétlik meg a leírások, mert azt a Moodle közvetlenül fölöttük jeleníti meg.
