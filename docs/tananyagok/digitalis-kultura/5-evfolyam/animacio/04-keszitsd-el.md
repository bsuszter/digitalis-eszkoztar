# 🎨 Készítsd el! – Váratlan találkozás

<div class="article-intro"><strong>ANIMÁCIÓ · 4. ÁLLOMÁS / 6</strong><br>A vázlatodból most legalább tíz képkockás, követhető animáció készül.</div>

## 🎯 A feladat

Készítsd el a két szereplő **váratlan találkozását** úgy, hogy a néző a mozgásból is értse a történetet!

[🎬 Nyisd meg a Mini Animációs Stúdiót!](https://interaktivfeladat.hu/jatek/animacio/){ .md-button .md-button--primary target="_blank" rel="noopener" }

## ✅ Készen vagy, ha…

- [ ] Van legalább 10 képkocka, két szereplővel.
- [ ] A mozgás fokozatos, a fordulat és befejezés érthető.
- [ ] Használtam legalább egy tudatos irányváltást, tükrözést vagy méretváltozást.
- [ ] Beillesztettem egy vagy két rövid, jól elhelyezett feliratot.
- [ ] Elmentettem a szerkeszthető JSON-projektet.
- [ ] Ha párban dolgoztunk, mindketten szerkesztettünk.
