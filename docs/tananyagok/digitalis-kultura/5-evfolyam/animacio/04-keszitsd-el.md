# 📤 Mentsd és add be! – Váratlan találkozás

<div class="article-intro"><strong>ANIMÁCIÓ · 4. ÁLLOMÁS / 4</strong><br>A kész történetből szerkeszthető projektet és lejátszható filmet is mentesz, majd feltöltöd a Moodle-ba.</div>

## 💾 1. Mentsd el a szerkeszthető projektet!

A **💾 Mentés** gombbal **JSON**-fájl készül. Ezt később a **📂 Betöltés** gombbal újra megnyithatod és szerkesztheted.

## 🎞️ 2. Exportáld a filmet GIF-ként!

A **🎞 GIF** gomb elkészíti a lejátszható animációt. A GIF a kész film, míg a JSON a szerkeszthető munkafájl.

[🧰 Mentés, betöltés és GIF](https://bsuszter.github.io/digitalis-eszkoztar/eszkoztar/mini-animacios-studio/lejatszas-mentes/){ target="_blank" rel="noopener" }

## 📤 3. Add be a Moodle-ban!

Keresd meg a két letöltött fájlt, nevezd el őket érthetően, és töltsd fel a megfelelő Moodle-feladatba.

Például: **Talalkozas_Kiss_Anna.json** és **Talalkozas_Kiss_Anna.gif**.

Páros alkotás esetén egy közös projekt készül; a tanár által megadott beadási módot kövessétek.

## 🏅 Értékelés – 50 pont

| Szempont | Pont |
| --- | ---: |
| A történet felépítése és érthetősége | 10 |
| Fokozatos, követhető mozgás | 15 |
| Ötletesség, váratlan fordulat | 10 |
| Az animációs eszközök tudatos használata | 10 |
| A JSON és GIF megfelelő beadása | 5 |
| **Összesen** | **50** |

A **jó, egyszerű megoldás is lehet teljes értékű**: a történet érthetősége és a mozgás tudatos megvalósítása fontosabb, mint a sok díszítés. Páros munka esetén az együttműködésről külön fejlesztő visszajelzést kapsz; a szakmai pontozás ugyanaz.

## ✅ Utolsó ellenőrzés

- [ ] Megvan a JSON-projektfájl.
- [ ] Megvan a GIF-fájl.
- [ ] Lejátszottam a kész GIF-et.
- [ ] Mindkét fájlt feltöltöttem a megfelelő Moodle-feladatba.
