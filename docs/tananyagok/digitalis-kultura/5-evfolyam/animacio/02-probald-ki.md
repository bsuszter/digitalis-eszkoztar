# 🎾 Próbáld ki! – Mozduljon meg!

<div class="article-intro"><strong>ANIMÁCIÓ · 2. ÁLLOMÁS / 6</strong><br>Irányított, egyéni feladat. Itt még mindenki saját maga próbálja ki a programot.</div>

## 🎯 A feladat

**Küldetés:** készíts rövid animációt, amelyben **egy szereplő** a kép egyik oldaláról a másikra halad! Válassz hozzá **egy hátteret**, és készíts **legalább 6 képkockát**!

[![Képkockánként mozgó labda](../../../../images/tananyagok/animacio/labda-kepkockak.svg)](../../../../images/tananyagok/animacio/labda-kepkockak.svg){ target="_blank" rel="noopener" }

[🎬 Nyisd meg a Mini Animációs Stúdiót!](https://interaktivfeladat.hu/jatek/animacio/){ .md-button .md-button--primary target="_blank" rel="noopener" }

## 🧩 Így készül a mozgás – hat lépésben

Haladj sorban! A képek a Mini Animációs Stúdió eredeti kezelőfelületét mutatják.

???+ example "1. Készíts új projektet!"

    Kattints az **Új** gombra, és válassz egy egyszerű hátteret!

    [![A háttér kiválasztása az elemtárból](../../../../assets/animacio/eredeti/01-hatter-valasztasa.png)](../../../../assets/animacio/eredeti/01-hatter-valasztasa.png){: target="_blank" rel="noopener noreferrer" }

??? example "2. Helyezz el egy szereplőt!"

    Válassz egy figurát az **Elemtárból**, és helyezd a kép bal oldalára! Hagyj neki helyet a mozgáshoz.

    [![Egy pingvin elhelyezése a háttéren](../../../../assets/animacio/eredeti/02-szereplo-elhelyezese.png)](../../../../assets/animacio/eredeti/02-szereplo-elhelyezese.png){: target="_blank" rel="noopener noreferrer" }

??? example "3. Duplikáld a képkockát!"

    Kattints a **Duplikálás** gombra! Így az új képkockán az előző kép minden eleme a helyén marad.

    [![A Duplikálás gomb és a képkockasor](../../../../assets/animacio/eredeti/03-kepkocka-duplikalasa.png)](../../../../assets/animacio/eredeti/03-kepkocka-duplikalasa.png){: target="_blank" rel="noopener noreferrer" }

??? example "4. Mozdítsd el egy kicsit!"

    A második képkockán húzd a szereplőt kissé jobbra! Figyeld meg a két képkocka közötti kis változást.

    [![A szereplő óvatos elmozdítása](../../../../assets/animacio/eredeti/04-szereplo-elmozditasa.png)](../../../../assets/animacio/eredeti/04-szereplo-elmozditasa.png){: target="_blank" rel="noopener noreferrer" }

??? example "5. Ismételd meg!"

    Duplikáld újra a képkockát, és mozdítsd tovább a szereplőt! Legyen **legalább 6 képkockád**.

    [![Az egymás után következő képkockák](../../../../assets/animacio/eredeti/05-ismetelt-duplikalas.png)](../../../../assets/animacio/eredeti/05-ismetelt-duplikalas.png){: target="_blank" rel="noopener noreferrer" }

??? example "6. Játszd le!"

    Indítsd el az animációt! Nézd meg **kétféle sebességgel**! Ha ugrál a mozgás, módosítsd az elmozdításokat, és játszd le újra!

    [![Lejátszás és a sebesség beállítása](../../../../assets/animacio/eredeti/06-lejatszas-sebesseg.png)](../../../../assets/animacio/eredeti/06-lejatszas-sebesseg.png){: target="_blank" rel="noopener noreferrer" }

## ✅ Készen vagy, ha…

- [ ] Van legalább 6 képkockám.
- [ ] Ugyanaz a szereplő látható minden képkockán.
- [ ] A szereplőt fokozatosan mozdítottam el.
- [ ] Lejátszottam és ellenőriztem az animációt.
