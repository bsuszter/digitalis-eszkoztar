# 📤 Add be! – Projekt és kész film

<div class="article-intro"><strong>ANIMÁCIÓ · 6. ÁLLOMÁS / 6</strong><br>Most kétféle fájlra lesz szükséged: a szerkeszthető projektre és a lejátszható animációra.</div>

## 1. Mentsd a projektet!

A **💾 Mentés** gombbal **JSON**-fájl készül. Ezt később a **📂 Betöltés** gombbal újra szerkesztheted.

## 2. Exportálj GIF-et!

A **🎞 GIF** gomb létrehozza a lejátszható filmet. A GIF önmagában **nem szerkeszthető projekt**, ezért a JSON-t is őrizd meg!

[🧰 Mentés, betöltés és GIF](https://bsuszter.github.io/digitalis-eszkoztar/eszkoztar/mini-animacios-studio/lejatszas-mentes/){ target="_blank" rel="noopener" }

## 3. Add be a Moodle-ban!

Keresd meg mindkét letöltött fájlt, adj nekik beszédes nevet, majd töltsd fel a megfelelő Moodle-feladatba. Például: **Talalkozas_Kiss_Anna.json** és **Talalkozas_Kiss_Anna.gif**. Párban egy közös munkát készítetek; a tanár által kért beadási módot kövessétek.

!!! warning "Az automatikus mentés nem beadás"
    Mindkét fájlt ténylegesen le kell tölteni és fel kell tölteni a Moodle-ba.

## 🏅 Értékelés: 15 pont

| Szempont | Pont |
| --- | ---: |
| Legalább 10 képkocka, működő animáció | 3 |
| Fokozatos, követhető mozgás | 4 |
| Kezdet – találkozás – befejezés | 3 |
| Kreatív, érthető fordulat | 2 |
| Tudatos irányváltás, tükrözés vagy méretváltozás | 2 |
| JSON és GIF megfelelő beadása | 1 |
| **Összesen** | **15** |

A **jó, egyszerű megoldás is teljes értékű**. Páros munka esetén az együttműködésről külön fejlesztő visszajelzés jár, nem plusz pont. 

## ✅ Utolsó ellenőrzés

- [ ] Megvan a projekt JSON-fájlja.
- [ ] Megvan a GIF-fájl.
- [ ] A kész GIF-et lejátszottam.
- [ ] Mindkét fájlt feltöltöttem a megfelelő Moodle-feladatba.
