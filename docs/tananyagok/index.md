# Tananyagok

Itt kapnak helyet a **teljes, tanulóknak szánt tananyagok és projektlépések**.

A Digitális eszköztár és a tananyagok szerepe eltér:

- **Digitális eszköztár:** hogyan tudsz egy konkrét digitális műveletet elvégezni.
