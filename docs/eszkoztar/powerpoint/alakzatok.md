# 🔷 Alakzatok, igazítás és csoportosítás

## Alakzat beszúrása

1. Kattints a **Beszúrás → Alakzatok** menüre.
2. Válassz például téglalapot, kört vagy háromszöget.
3. Húzással rajzold meg. A **Kitöltés** és **Körvonal** beállításaival változtasd a színét, megjelenését.

## Pontos szerkesztés

- **Forgatás:** az alakzat fogantyújával vagy a forgatás menüben.
- **Másolás:** kijelölés után `Ctrl+C`, majd `Ctrl+V`.
- **Rétegsorrend:** **Előrehozás / Hátraküldés**, ha a formák takarják egymást.
- **Igazítás:** több kijelölt alakzatot pontosan egymáshoz rendezhetsz.
- **Csoportosítás:** a kijelölt alakzatok ezután egy egységként mozgathatók.

!!! example "Próbáld ki!"
    Rajzolj egy ablakot négy téglalapból. Igazítsd egymáshoz őket, majd csoportosítsd az egész ábrát!

!!! info "Pixel vagy vektor?"
    A fénykép képpontokból áll; a PowerPoint saját alakzatai általában méretezve is élesek maradnak.
