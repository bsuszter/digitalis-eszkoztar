# 🎞️ Új képkocka vagy duplikálás?

[🎨 Mini Animációs Stúdió megnyitása ↗](https://interaktivfeladat.hu/jatek/animacio/){: target="_blank" rel="noopener noreferrer" }

!!! info "Így használd a segítséget"
    A sematikus ábrák a működést magyarázzák, az eredeti képernyőképek a valódi gombokat és műveleteket mutatják. A képekre kattintva külön lapon, nagyobb méretben is megnézheted őket.


![A labda négy egymást követő helyzete](../../images/tananyagok/animacio/labda-kepkockak.svg)

## A két gomb nem ugyanazt csinálja

| Gomb | Mi történik? | Mikor jó? |
|---|---|---|
| **➕ Képkocka** | Új, üres képkockát készít. | Teljesen más jelenetet építesz. |
| **📄 Duplikálás** | Lemásolja a kijelölt képkocka jelenetét. | Kicsit mozdítanál valamit; folyamatos mozgást szeretnél. |

### Így néz ki a Duplikálás

[![A Duplikálás gomb és a lemásolt képkockák az animációs programban](../../assets/animacio/eredeti/03-kepkocka-duplikalasa.png)](../../assets/animacio/eredeti/03-kepkocka-duplikalasa.png){: target="_blank" rel="noopener noreferrer" }

A **Duplikálás** a teljes jelenetet másolja: az új képkockán minden a helyén marad, amíg változtatsz rajta.

### A legegyszerűbb mozgás

1. Tedd a labdát a vászon bal oldalára!
2. **Duplikáld** a képkockát!
3. Az új képkockán mozdítsd a labdát kissé jobbra!
4. Ismételd meg többször!
5. Nyomd meg a **▶ Lejátszás** gombot!

[![Kijelölt figura elmozdítása a következő képkockán](../../assets/animacio/eredeti/04-szereplo-elmozditasa.png)](../../assets/animacio/eredeti/04-szereplo-elmozditasa.png){: target="_blank" rel="noopener noreferrer" }

A képen a kijelölt szereplőt kissé arrébb húzzák. Minden újabb képkockán egy kis elmozdulásból áll össze a folyamatos mozgás.

!!! warning "Gyakori hiba"
    Ha minden új képkockán más-más helyről indítod a szereplőt, a mozgás ugrálni fog. Duplikálj, és egyszerre csak egy kisebb változtatást végezz!
