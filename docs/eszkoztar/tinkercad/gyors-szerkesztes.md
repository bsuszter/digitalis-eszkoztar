## Visszavonás és újra

<div class="step-stack">
  <div class="step-card"><span class="step-no">1</span><div><strong>Vond vissza az utolsó műveletet!</strong><span>Használd a <strong>Ctrl + Z</strong> billentyűkombinációt, ha az előző lépést szeretnéd visszacsinálni.</span></div></div>
  <div class="step-card"><span class="step-no">2</span><div><strong>Ha mégis szükség van rá, állítsd vissza!</strong><span>Az újra művelethez használd a <strong>Ctrl + Y</strong> vagy <strong>Ctrl + Shift + Z</strong> billentyűkombinációt.</span></div></div>
</div>

!!! tip "A visszavonás a kísérletezés része"
    Nyugodtan próbálj ki több megoldást! Ha nem jó az eredmény, vond vissza, és próbáld másképp. Ettől nem romlik el a terved.

## Kijelölés és törlés

<div class="mini-grid mini-grid--uses">
  <div class="mini-card"><span class="mini-icon">🖱️</span><strong>Egy elem</strong><span>Kattints az alakzatra!</span></div>
  <div class="mini-card"><span class="mini-icon">➕</span><strong>Több elem</strong><span>Tartsd lenyomva a <strong>Shift</strong> billentyűt, és kattints a további elemekre!</span></div>
  <div class="mini-card"><span class="mini-icon">▭</span><strong>Kijelölőkeret</strong><span>Üres területről indulva húzz keretet az elemek köré!</span></div>
  <div class="mini-card"><span class="mini-icon">🔲</span><strong>Minden elem</strong><span><strong>Ctrl + A</strong>: a terv összes elemének kijelölése.</span></div>
</div>

A kijelölt, felesleges elemet a **Delete** billentyűvel törölheted. Ha véletlenül rosszat töröltél, azonnal használd a **Ctrl + Z**-t!

## Másolás: melyiket használd?

- **Ctrl + C, Ctrl + V** – hagyományos másolás és beillesztés;
- **Ctrl + D** – duplikálás, amely a szabályos ismétléshez is használható;
- **Alt + húzás** – másolat készítése mozgatás közben.

<div class="quick-note">
  <strong>Ismétlődő mintához a Ctrl + D a fontos</strong>
  <span>Ha ugyanazt az eltolást, forgatást vagy más változtatást szeretnéd újra megismételni, nézd meg a <strong>Másolás és ismétlés</strong> leckét!</span>
</div>

## Gyakori gyorsbillentyűk egy helyen

| Művelet | Billentyű |
|---|---|
| Visszavonás | **Ctrl + Z** |
| Újra | **Ctrl + Y** vagy **Ctrl + Shift + Z** |
| Törlés | **Delete** |
| Minden kijelölése | **Ctrl + A** |
| Másolás / beillesztés | **Ctrl + C / Ctrl + V** |
| Duplikálás és ismétlés | **Ctrl + D** |
| Csoportosítás | **Ctrl + G** |
| Szétbontás | **Ctrl + Shift + G** |
| Furat típus | **H** |
| Igazítás | **L** |
| Tükrözés | **M** |
| Munkasíkra ejtés | **D** |
| Vonalzó | **R** |

!!! note "Nem minden művelethez kell gyorsbillentyű"
    A gombokat ugyanúgy használhatod a felületen. A billentyűkombinációk csak akkor hasznosak, ha gyorsabbá teszik a munkádat.

## Ha összetettebb a modelled

Később hasznos lehet egy elem **zárolása** vagy ideiglenes **elrejtése** is, hogy véletlenül ne mozdítsd el, illetve ne zavarjon szerkesztés közben. Ezek nem alapkövetelmények: csak akkor használd őket, ha valóban segítik a munkádat.
